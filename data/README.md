# Data

This project uses publicly available single-cell RNA-seq data from:

- **GEO accession:** GSE59114
- **Organism:** *Mus musculus*
- **Data type:** Single-cell RNA sequencing
- **Study:** Age-associated transcriptional changes in hematopoietic stem and progenitor cells

The dataset contains expression data from hematopoietic stem and progenitor cell populations, including:

- Long-term hematopoietic stem cells (LT-HSCs)
- Short-term hematopoietic stem cells (ST-HSCs)
- Multipotent progenitors (MPPs)

The analysis compares young and old cell populations to investigate age-associated changes in cell-cycle state.
